TWILIO POLICY PAGES — BEFORE PUBLISHING

These files are a starter policy site for GitHub Pages. They are NOT live yet.

REQUIRED BEFORE PUBLICATION:
1. Replace [REPLACE WITH YOUR EXACT REGISTERED SOLE PROPRIETOR BRAND NAME] in both HTML files with the exact A2P Brand name approved by Twilio.
2. Replace the contact placeholder in both files with an email address or other monitored contact method.
3. Review the policy text and confirm it accurately describes your actual use and data handling.
4. Keep privacy-policy.html and sms-terms.html together in the published site root.

FREE GITHUB PAGES PUBLISHING:
1. Create a GitHub repository named eb ay-ai-manager-policies (without the space: ebay-ai-manager-policies).
2. Upload index.html, privacy-policy.html, and sms-terms.html to the repository root.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. The URLs will resemble:
   https://YOUR-GITHUB-USERNAME.github.io/ebay-ai-manager-policies/privacy-policy.html
   https://YOUR-GITHUB-USERNAME.github.io/ebay-ai-manager-policies/sms-terms.html
6. Open both links in a private/incognito browser window to confirm they are public.

Do not enter the URLs in Twilio until they are live and the placeholders have been replaced.
